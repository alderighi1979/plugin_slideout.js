# Exemplo de Menu com SlideOut.js

Este projeto demonstra a implementação de um menu deslizante utilizando a biblioteca SlideOut.js. O menu é ativado por um botão e desliza para dentro e para fora da tela, proporcionando uma experiência de navegação fluida.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- SlideOut.js (https://github.com/Mango/slideout)

## Estrutura do Projeto

- **index.html**: O arquivo principal que contém a estrutura do site.
- **favicon.ico**: Ícone do site.

## Funcionalidades

- **Menu Deslizante**: Um menu que desliza para dentro e para fora da tela ao clicar no botão "Menu".
- **Responsividade**: O layout é adaptável e funciona bem em diferentes tamanhos de tela.
- **Estilo Personalizado**: O menu e o conteúdo têm estilos personalizados para uma melhor apresentação.
